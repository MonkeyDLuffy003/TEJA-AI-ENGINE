## What is TEJA AI Engine?

TEJA AI Engine is a lightweight, cloud-powered video generation pipeline.
It takes a simple text prompt and automatically generates a complete
narrated video — ready to post on YouTube or Instagram.

Built entirely with free tools. Runs from Android + Termux.
Outputs saved to Google Cloud Storage.

---

## How It Works

```
Your Prompt (text idea)
        ↓
Story + Script Generator  (Gemini AI)
        ↓
Scene Image Prompt Generator (Gemini AI)
        ↓
Voice Over Generator (Edge TTS)
        ↓
Video Builder (MoviePy)
        ↓
Upload to Google Cloud Storage
        ↓
Your video is ready to post
```

---

## Features — V1

- Text to Story Script generation
- Scene by scene image prompt generation
- English voiceover generation (US accent)
- Automatic video building (images + voice + music)
- Auto upload to Google Cloud Storage
- GitHub Actions automation pipeline
